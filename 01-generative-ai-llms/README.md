# Lesson 1: Generative AI and Large Language Models

## Learning Objectives

By the end of this lesson, I should be able to:

- Explain the difference between traditional machine learning and generative AI.
- Define a Large Language Model (LLM).
- Explain what tokens are and why LLMs use them.
- Describe embeddings at a conceptual level.
- Explain the basic purpose of the Transformer architecture.
- Describe self-attention conceptually.
- Explain what a context window is.
- Distinguish between model training and inference.
- Explain how an autoregressive language model generates text.
- Distinguish between prompting, RAG, fine-tuning, tool calling, and agentic AI.
